Browsing (page agent)

Applies when Go off page is ticked in the sidebar.
The URL every new tab opens on. A run that begins here is told outright that this is the dashboard, not the subject of the request, and that its first step is to navigate — otherwise the model reads the dashboard and reports the answer isn't on it. Any path under this URL counts; Firefox's own about:newtab / about:home are always recognized. Leave empty if new tabs open on something you do want read.

Screen vision (page agent)

Lets the page agent handle pages the DOM tools can't drive — canvas/WebGL games and apps whose controls are invisible to observe. When a grounding model is picked, the agent gains two tools: screenshot (the page image is attached to the chat — the default model above must be vision-capable to look at it) and click_screen, which clicks a verbally-described target at the coordinates this model finds. Leave empty to disable both.
Needs a model trained to detect — to return a box for a described object. Gemma 4 and Qwen-VL both are, so same as the chat model is normally right and costs no extra model: measured on mock/game.html, gemma4-12b locates buttons on its own screenshots to within ~5 px in ~0.8 s, and says so plainly when the target isn't on screen. Small models are noticeably worse (gemma4-e4b: 13–47 px, one outright miss), so pick a separate bigger model here if your chat model is small or text-only. Populated by Test above. Run npm run ground-check to measure any model yourself.

Read aloud

Right-click selected text → Ask LLM → Read aloud. The gateway synthesizes the whole selection in one request (/v1/audio/speech) and the extension plays it — one request keeps one voice, at the cost of waiting for the whole clip (roughly half its spoken length). Stop reading appears in the same menu while it talks.
lmgw's TTS models (transcription models are filtered out). Populated by Test above.
A voice name, never a file path: either one the model ships or a preset defined on the model in lmgw (Audio → edit model → Voice presets), which is where a reference clip for voice cloning belongs. The names the gateway advertises for this model are offered as suggestions; an unknown one is rejected by the upstream. Leave it empty to get the model's default preset — without one, a cloning model like fish-audio picks a new random speaker every time you press play.
1 = the model's natural pace. Only sent when it isn't 1; not every model honours it.
